# АкваМастер — магазин сантехники

React (Vite) + Express + PostgreSQL.

## Запуск
1. В pgAdmin создай базу `PlumbingHere` и выполни в ней `backend/PlumbingHere.sql` (таблицы и тестовые данные).
2. В `backend/` скопируй `.env.example` в `.env` и впиши свой пароль PostgreSQL
   (имя базы в `PG_DATABASE` должно совпадать с созданной).
3. Бэкенд: `cd backend`, `npm install`, `npm run dev` (порт 3001).
4. Фронтенд: `cd frontend`, `npm install`, `npm run dev`, открыть http://localhost:5173
   (бэкенд и фронтенд запускаются в двух разных терминалах; если запущен другой проект на этих портах, останови его).

Если база уже была создана раньше, выполни `backend/PlumbingHere.sql` ещё раз: он пересоздаёт все таблицы (данные сбросятся).

## Что есть на сайте
- Каталог: поиск работает сразу при вводе (без кнопки), с подсказками; фильтр по категории и цене, карточка товара, отзывы (один отзыв на товар, фильтр мата).
- Корзина (в БД): не больше 10 товаров в корзине (и не больше 10 шт. одного), на одну дату доставки суммарно
  принимается не больше 10 товаров от всех покупателей (больше сотрудников в этот день нет); один заказ = один номер и одна сумма.
- Заказы: «Ожидает оплаты» → «Оплачен» → «В работе» → «Готов к выдаче» → «Доставлен» (или «Отменён»).
- Скидки: 10% на первый заказ или купон (SALE10, SUPER20), применяется одна, самая выгодная; купон один раз на пользователя.
- Личный кабинет, смена пароля, восстановление пароля по коду из письма (`/forgot`).
- Админ-панель: товары, категории (удалённая категория переносит товары в «Без категории»), заказы, купоны, пользователи.
  Админ не удаляет и не меняет данные пользователей, не удаляет заказы (чеки) и не меняет адрес и дату доставки; оплаченный заказ нельзя вернуть в «Ожидает оплаты».
  Удалённый админом отзыв заменяется пометкой «удалён за нарушение политики».
- Светлая и тёмная тема; страница «Технические работы», если бэкенд или БД недоступны.
- Пароли хранятся в виде bcrypt-хешей. Права проверяются на сервере по токену, который выдаётся при входе: это подписанная строка (подпись ставится секретом `TOKEN_SECRET` из `.env`), поэтому подменить id пользователя в запросе нельзя. В базе токены не хранятся.

## Восстановление пароля по почте
В `backend/.env` заполни `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` (см. `.env.example`).
Без SMTP код сброса печатается в консоль сервера.

## Фото товаров
У товара поле «Ссылка на фото» (прямая ссылка на картинку). Если её нет или она не открывается, показывается заглушка.
